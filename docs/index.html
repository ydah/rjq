The jq you know, in the Ruby you use.

Practical compatibility

Pipes, filters, assignments, paths, regex, modules, streaming, and the built-ins that make jq productive.

Streaming by design

An incremental JSON parser and writer keep input moving. Streams stay lazy until jq semantics require collection.

CLI and library

Run familiar filters in a shell, compile them once in Ruby, or consume results as an Enumerator-backed stream.

Bounded when needed

Set limits for nesting, calls, instructions, output, string size, and regex time when processing untrusted input.

One filter. Two ways to run it.

Use rjq at the prompt, then bring the same expression into your application without changing mental models.

From the command line

$ rjq -r '.users[] | select(.active) | .name' users.json
Ada
Grace

From Ruby

require "rjq"

filter = Rjq.compile(".users[] | select(.active) | .name")
filter.run(data).to_a
# => ["Ada", "Grace"]
